# Mehedi IPTV

Android TV focused IPTV player.

- Playlist: https://raw.githubusercontent.com/mehedi6070/Mehedi-IPTV/refs/heads/main/channels.m3u
- Auto refresh: every 2 minutes while the app is running
- Last successful playlist is cached for offline fallback
- Automatic categories when the M3U does not provide group-title
- Android TV remote navigation
- Full-screen Media3 player
- Live estimated stream speed only

Build with GitHub Actions: Actions -> Build Mehedi IPTV APK.
