# Mehedi IPTV

Android TV/IPTV starter project implementing the requested interaction model.

## Included
- M3U playlist: `https://raw.githubusercontent.com/mehedi6070/Mehedi-IPTV/refs/heads/main/channels.m3u`
- Background channel refresh every 2 minutes
- Full-screen Media3 player
- Channel overlay: `Channel Name | Number`
- Left/right horizontal swipe panels
- Up/down swipe channel switching
- Android TV remote D-pad support
- Online counter API: `https://meheditv.site.je/api/online.php`
- Total counter API: `https://meheditv.site.je/api/total.php`
- Bengali scrolling ticker text

## Build
Open the folder in Android Studio and let Gradle sync. Then build/install the `app` module.

Note: this is a clean project created from scratch because no existing source project was supplied.
